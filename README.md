## The entry

A clinic receptionist rings a patient to confirm next week's check-up — a
routine, everyday call, delivered with total professional calm. One word in
the message is not the one the clinic meant to send: the appointment being
confirmed is a standard screening, and the word that landed in its place
turns the whole thing into something the patient will never forget. Nothing
in the message flags the slip; it reads exactly like a genuine confirmation,
which is what makes it land. The humour comes entirely from that single
substituted word — the rest of the message is perfectly ordinary.

## How it works

`main.py` writes the single confirmation message to `/output/entry.txt`
using only the Python standard library. The output is deterministic — the
same message, byte for byte, on every run.
